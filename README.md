# Java Word Guessing Game

A simple word guessing game developed using Java.

## Description

In this game, a random word is selected from a predefined word list.  
The player tries to guess the word by entering letters.

For each correct guess, the corresponding letters are revealed.  
For an incorrect guess, the number of remaining attempts is reduced.

The game ends when the player successfully guesses the word or runs out of attempts.

## Technologies

- Java
- Object-Oriented Programming (OOP)

## Features

- Random word selection
- Letter-by-letter guessing
- Limited number of attempts
- Display of the current guessed word
- Win and lose conditions

## Project Structure

- `Project1.java` — Main class that starts the game
- `Game.java` — Handles the game logic and user input
- `WordBank.java` — Stores the word list and selects a random word

## How to Run

Run the `Project1.java` file to start the game.

## Example

The game displays the current progress of the word and the number of remaining attempts.

The player enters a letter and receives feedback indicating whether the guess was correct or incorrect.
